## Design as built

- **Never committed:** `game/assets/pack/` is git-ignored. After syncing (18 files) and a
  full import, `git status --porcelain` shows nothing under `game/assets/` (pack PNGs and their
  `.import` files are all ignored). `git diff --cached --name-only main | grep assets/pack` is empty.
- **All or nothing:** `pack_assets.gd` returns `null` (→ placeholder for the whole renderer)
  when any sheet is missing, when a sheet's size differs from the measured `sheet_size`, or when
  the JSON's `frame_size`/`feet_y` differ from `colonist_sprites.gd`'s `FRAME_SOURCE_SIZE` (64) /
  `FRAME_FEET_Y` (47). There is never a mix of pack and placeholder colonists.
- **Measured, not remembered:** `colonist_pack.json` is written by
  `B2-measure_pack_frames.py` from the PNGs. Body_A frames are 64x64; in every idle/walk/carry
  frame the alpha box ends at row 48 (exclusive), i.e. feet on row **47**, the same grounding the
  placeholder already uses, so `SPRITE_POSITION_OFFSET` is unchanged. `side` sheets face right
  (checked visually), so the existing flip-for-left rule applies.
- **Mapping** (from the entry): Idle, Walk, Carry_Idle, Carry_Walk; Slice for chop; Crush for
  mine and dig. Frame counts match the placeholder (walk 6, idle 4), so walk/idle timing is
  unchanged (`floor(t * count)` over one tile crossing).

## Decisions taken without an explicit line in the entry (owner, please confirm)

1. **The "private notes" were not available to me** (not in the repo or the pack folder). I used
   only what the entry itself says (Slice→chop, Crush→mine/dig).
2. **Build (`site_work`) also uses Crush** with the pack. The entry does not name a sheet for it;
   leaving it out would make building colonists stand idle with the pack (the placeholder has a
   `build_*` strip). One line in `B2-measure_pack_frames.py` (`ANIMATIONS["build"]`) changes it.
3. **Pack work animations loop.** The existing renderer drives frames from `t`, which clamps
   at 1 once a colonist stops, so a work strip would freeze on its last frame. With the pack, a work
   animation loops once per tile-crossing duration (2.0 s at x1, scales with speed, freezes when
   paused, all driven by `advance()`, no autoplay timer). The placeholder keeps its old timing
   exactly (`_loop_work` is false without the pack).
4. **Size:** the entry says colonists are 24 px tall; the Body_A figure is **30 px** tall
   (rows 18–47) at native 1.0 scale, the placeholder 17 px. I kept native scale (style.md:
   "native size, never squashed"; 0.8 would break pixels). Changing it is an owner call.

## Known limitations

- **Not checked on the native build.** The screenshots come from the real renderer in a
  windowed Godot run, not from the exported game. The owner still has to confirm on the native
  build, as the acceptance asks. An exported build includes only imported textures: run
  `tools\sync_pack_assets.ps1` (which imports) before exporting.
- The cargo and tool badges (`CARRIED_MARKER_OFFSET`, `TOOL_MARKER_OFFSET`) are offsets
  from the 64x64 frame's top-left, so they float up and to the left of the figure. This is
  unchanged from before, the placeholder looks the same, and it fits B3 (items).
- A working colonist faces its last movement direction, not the tile it works on (unchanged).
- Body_A is the pack's bare base body (no clothes or hair layers); that is what the entry
  names.
- The Slice strip includes the pack's white swing-arc effect frames.
