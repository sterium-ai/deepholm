## Tests

`test_world_pack.gd` was extended, not weakened. Every changed assertion
replaces a line with a version that checks more:

- item coverage also accepts a `PACK_ITEM_MAP` cell, so the pack-only kinds
  must be mapped **or** listed with a reason, never both and never neither;
- the "cell exists in the placeholder" check also allows pack-only item
  cells, which by design have no placeholder cell;
- the vertical workbench gets its own 1x2 ceiling instead of the 1x1 one.

New assertions: without the pack, pack-only items stay undrawn; with the
pack, every PACK_ITEM_MAP kind has an icon and a ground icon; carried-cargo
icons are unchanged; sand stays undrawn.

## Known limitations

- A **completed** vertical workbench still draws horizontally: core stores
  no orientation on a finished object, so the viewer cannot tell. Only the
  build site shows the vertical art. Fixing this needs a core field, which is
  outside B7's scope.
- Bed and sand stay placeholder (see the table above).
- Pack-only item kinds have no placeholder icon, so without the pack they
  are not drawn on the ground (unchanged from before B7).
- stone_blocks uses a dark slate block (the pack has no grey cut block) and
  flint a dark chipped shard. Both are judgement calls.
