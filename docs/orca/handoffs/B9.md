## Result

1. **Dig needs a shovel.** `content/items.json` adds tool item `shovel`;
   `content/jobs.json` changes dig's `needs_tool` from `pick` to `shovel`;
   `content/recipes.json` adds a workbench recipe `shovel` (wood x2 + stone x1).
   A dig with no shovel blocks with `blocked_no_tool`, remedy
   `craft_or_find:shovel`, even with a pick lying beside the digger.
2. **Starting kit.** No scenarios.json change was needed:
   `scenario_builder._run_needed_tools` already spawns one ground tool per
   distinct `needs_tool` kind, so the start now has a shovel and a pick.
3. **Adjacent stance.** `toil_bindings.gd` adds `dig` to the adjacent-work
   kinds (`ADJACENT_WORK_KINDS = ["site_work", "dig"]`), so the go_to toil
   ends beside the target (Chebyshev 1) and a digger standing on the target
   steps off first. `toil_executor.gd` gets a `step_off_allowed` callable:
   `_step_off_tile` prefers a neighbour that is not a trench and falls back to
   the old first neighbour. Without that, a second dig next to a fresh trench
   stepped into the trench and trapped the digger. Mine and chop already
   worked from an adjacent tile (impassable targets); the new test pins mine.
4. **Tool tip calibration.** The viewer leans the body up to +/-8 px
   (`MAX_WORK_OFFSET`) toward the target so the measured tool tip lands on the
   target tile. Tips are measured on the impact frame (frame 3) by
   `B9-measure_pack_frames.py` and recorded in `colonist_pack.json`
   (`measured_by` names the script):
   - chop (Slice strip): down [34,62], up [27,4], side [63,35]
   - mine / dig / build (Crush strip): down [31,61], up [38,15], side [56,42]
5. **Trench tile.** `world_pack.json` trench source rect moves from
   [32,352] to [224,384]: the Wall_Tiles dark pit bottom row with its lit south
   rim, clearly darker than soil.
6. **Plant animation.** `plant_down/up/side` from the pack's Collect_Base
   sheets (8 frames, 6 fps, no tool tip); `pack_manifest.json` lists the three
   sheets; `colonist_sprites.gd` maps `plant_sapling` to `plant`.

## Known limitations

- **Dig shares mine's Crush strip.** The pack has no dig or shovel strip and
  new art is barred (A20 rejected), so owner item "dig animation" is only
  partly met. A real dig strip waits on the A21 art commission.
- **No shovel icon.** The held tool uses the existing stand-in, and map_view
  draws a ground shovel with the magenta fallback. map_view is out of scope
  (B8 is in flight there); a `world_pack.json` note records the follow-up.
- The Crush up-facing tip is partly hidden behind the head; it is measured
  but hard to see in the north shot.
- The +/-8 px clamp: on the east dig the body leans slightly back from the
  ideal; the offset also applies on windup frames, not only the impact frame.
- Collect has no tool tip, and the planter stands on its own tile (plant
  target stance was not in scope).
- A dig in a one-wide corridor still cuts the corridor: step-off avoids
  trenches but the trench itself is impassable by design (trench depth and
  refilling are non-goals).
- B2's `--check` measuring mode is superseded by `B9-measure_pack_frames.py`
  for tool tips. B7's generator is stale, so the trench rect is a hand edit
  in `world_pack.json`.
- A pre-existing scheduler quirk with disconnected regions showed up while
  writing the tests; the tests avoid it and it is not changed here.
- The first baseline run was contaminated (pack art not synced in this
  worktree); the pack is now synced locally.
