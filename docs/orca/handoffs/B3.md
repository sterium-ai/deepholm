## Design as built

- **Same mechanism as B2.** Sheets listed in `pack_manifest.json`, copied by
  `tools\sync_pack_assets.ps1` into git-ignored `game/assets/pack/`, loaded by `pack_assets.gd`,
  placeholder fallback. All or nothing across the whole world: `world_pack()` returns the TileSet
  and the actor frames together or `{}`, so one missing sheet, or one whose size differs from the
  measured one, terrain/prop or actor alike, keeps the whole map on the placeholder TileSet and
  the actors undrawn.
- **No new TileSet resource, no change to `tile_atlas_map.gd`'s tables.** `world_tile_set()`
  builds, in memory, one texture per mapped source on the placeholder's own source ids and atlas
  coords (each sprite bottom-centred in the source's `cell_size` cell; grounded props get the
  existing `texture_origin.y = (cell h − footprint h) / 2`). Unmapped sources are copied from the
  placeholder. So the shoreline overlay/backing, incremental refresh, construction ghosts
  (they read the TileSet) and the progress bar (footprint-based, B4) work unchanged. Composing at
  runtime keeps pack pixels out of the repository (licence).
- **Measured, not remembered.** `B3-measure_pack_world.py` holds the choices (a search window per
  kind on a sheet) and measures the rest from the PNGs: sheet size, alpha bounding box inside the
  window, actor frame boxes, feet rows. It rejects a choice that breaks the art rules: terrain and
  wall cells must be fully opaque, each grass blob cell must be transparent on the side its name
  says (the pack's grass blob turned out to use the placeholder's 5x5 layout cell for cell), props
  within ceilings. `--check` verifies the committed JSON against the pack.
- **Owner's scale rule ("props ≤ 1 casilla salvo árboles").** 1x1 props ≤ 16x24, workbench ≤ 32x28,
  trees ≤ 32x64 with the pack (the large tree is 32x62; the placeholder ceiling 32x48 stays for
  the generated art). Recorded in `docs/art/style.md`.
- **Three tree sizes** (small 9x25, medium 16x32, large 32x62). `map_view.gd` picks one per tree
  tile by `hash(Vector3i(seed, x, y))`. Found while capturing: Godot's string hash (`"seed:x:y"`,
  as the grass variants use) multiplies by 33 per character, so modulo 3 it only sees the last
  character, and every tree came out the same size. The Vector3i hash mixes properly; the grass
  variant code was left as it is (not this task). Only the tree source varies: the hazard decor
  shares the resources source with the stone/wood icons and keeps its own cell.
- **Actors.** `actor_sprites.gd` draws every `get_actors_with_health()` actor that is not a
  colonist: `wolf` → `Mobs/Wolf` side sheets, a wolf-def actor of faction `raiders` (the
  `raider_incursion` incident spawns those) → `Orc Crew/Orc`, `trader` → `Citizen_F/Peasant_A`.
  Idle, or walk on the refresh where its tile changed; flipped after a step left (side sheets face
  right); grounded on each animation's measured feet row with the colonists' formula; frames from
  its own clock, frozen while paused. Snaps to tiles (no glide). Added below the colonist layer so
  every health bar stays on top.
- **Icons.** Pack icons are the sprite's own pixels, uniformly scaled into the existing 9.6 px box
  (stockpile) and badge sizes (cargo, tool), never squashed. The placeholder icons are drawn
  exactly as before.
