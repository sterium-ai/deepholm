# A0 handoff: foundation audit against the long-term ambition

> **In short:** This change is an audit, not a fix. It adds three things:
> `docs/architecture/foundation-audit.md` (the evidence), a one-page Spanish summary for the
> owner, and five headless benchmarks with a shared helper. It also appends 18 proposed
> `A*` tasks to the backlog for the owner to accept or reject. No production code changed. The
> headline: the rules are solid, but the machinery does not scale yet. At 1,000 idle
> colonists one tick takes 1.9 s, and 95% of that is combat targeting, which is O(A²). With
> work, the scheduler and route search add seconds more. Ten colonists with 2,000 open orders
> take 235 ms per tick.

## Known limitations

- **Contention.** During the benchmark runs the machine was also running the owner's game
  window and two other agent worktrees' Godot processes. The benchmarks are single-threaded
  on a 16-thread CPU, and two full runs (pre- and post-rebase) agreed within about 10% on most lines
  and up to 25% on a few. The
  audit still tells readers to treat numbers as ±25%.
- **Single samples.** Route, save and content numbers are single runs. The tick numbers are
  means over up to 29 ticks.
- **Coverage of the workloads.** Tilling (no tools), idle and hunger only. Construction,
  hauling, real combat and incidents are not driven. Construction's unbounded `_route_cost()`
  searches are a code finding, not a measurement.
- **`profiled_tick()` copies `tick()`.** If R12's `TickPipeline` changes `tick()`, the copy
  must follow. `hash_match` fails loudly when it drifts.
- **`bench_long_session.gd` and `bench_tick_scaling.gd` read private fields**
  (`_scheduler.queue._jobs`, `_event_log._events`, `_tile_grid.dirty_cells`) to print sizes.
  R15 should give them a test surface.
- **Exit-time warnings.** `ObjectDB instances were leaked at exit` appears for every
  benchmark, as it does for the existing tests. The leak check in `bench_save_load.gd`
  quantifies it per world (32 Objects), and the audit (§4.2) explains the cause: reference
  cycles through bound Callables.
- **Not linked from the docs index.** The audit is not linked from
  `docs/architecture/README.md` or `source-of-truth.yaml` (not owned paths).
- **Nothing measured on a phone.** A18 is the task that would measure it.
